# БАГ-001: Счётчик корзины не обновляется при добавлении товара в офлайн-режиме, а затем при восстановлении сети дублируется

**ID:** BUG-001  
**Приоритет:** Высокий (High)  
**Серьёзность:** Критический (Critical)  
**Обнаружено в версии:** 2.3.1 (Android 11)  
**Тест-кейс:** TC-03, шаг 2–4  
**Окружение:**  
- Устройство: Samsung Galaxy S20, Android 11  
- Сеть: офлайн → переключение на 4G  

**Шаги воспроизведения:**  
1. Отключить интернет на устройстве (режим «В самолёте»).  
2. Открыть приложение, перейти в карточку товара «Смартфон X».  
3. Нажать «В корзину» – появляется сообщение «Нет подключения» (офлайн).  
4. Включить интернет (4G).  
5. Снова нажать «В корзину» для того же товара.  

**Фактический результат:**  
- В офлайн-режиме товар не добавляется, но после включения сети при повторном нажатии товар добавляется ДВАЖДЫ (дублируется).  
- Итоговая стоимость удваивается, счётчик корзины показывает 2 вместо 1.  
- При просмотре корзины видны две одинаковые позиции.  

**Ожидаемый результат:**  
- При отсутствии сети товар не должен добавляться, а после восстановления соединения одно нажатие должно добавить товар только один раз.  
- Счётчик и итог должны соответствовать количеству реальных добавлений.  

**Дополнительная информация:**  
- Проблема воспроизводится только если между офлайн-кликом и онлайн-кликом прошло менее 5 секунд (гонка состояний).  
- В логах видно, что при офлайн-запросе создаётся локальный идентификатор, который не очищается при ошибке.
