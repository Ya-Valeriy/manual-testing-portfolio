# Портфолио по ручному тестированию

**Автор:** Валерий Яманкин  
**Цель:** Демонстрация навыков ручного тестирования, тест-дизайна, работы с БД и API.

## Содержание
1. **Тест-дизайн** — чек-листы, тест-кейсы и майнд-карты.
2. **Баг-репорты** — примеры оформления дефектов.
3. **SQL-запросы** — скрипты для проверки данных.
4. **API-тестирование** — коллекция Postman и результаты.
5. **Анализ требований** — User Story и RTM.

## Технологии
- Тест-менеджмент: TestLink, Jira
- API: Postman, REST
- БД: PostgreSQL, SQL
- Моделирование: Draw.io, PlantUML
