# User Story: Приёмка товара на склад

**ID:** US-001  
**Приоритет:** Высокий (High)  
**Итерация:** Sprint 5  

**Роль (Who):** Кладовщик  
**Действие (What):** Хочу принимать товар по накладной с использованием RF-сканера  
**Ценность (Why):** Чтобы быстро и без ошибок регистрировать поступление товара на склад, уменьшая время приёмки и предотвращая расхождения в учёте.

---

## Критерии приемки (Acceptance Criteria)

| № | Критерий | Проверяемый аспект |
|---|----------|---------------------|
| 1 | При сканировании штрих-кода товара система автоматически находит его в накладной и добавляет в список приёмки | Идентификация товара по штрих-коду |
| 2 | Кладовщик может вручную изменить количество, если оно отличается от указанного в накладной | Гибкость ввода количества |
| 3 | Если сканируется товар, которого нет в накладной, система выдаёт предупреждение и не добавляет его | Валидация соответствия накладной |
| 4 | При успешном завершении приёмки система печатает этикетки для всех принятых товаров | Интеграция с печатью |
| 5 | Обновляются остатки в реальном времени (в течение 1 секунды после подтверждения) | Производительность и согласованность данных |

---

## Технические требования (Non-functional)

- Время отклика при сканировании ≤ 500 мс.
- Поддержка 50 одновременных приёмок без деградации производительности.
- Журналирование всех действий для аудита (кто, когда, какой товар принял).
