# Матрица трассировки требований (RTM)

**Проект:** Интернет-магазин (Мобильное приложение)  
**Модуль:** Корзина и оформление заказа  
**Дата составления:** 10.08.2026  
**Автор:** Валерий Яманкин

## Список требований (функциональных)

| ID требования | Описание требования (User Story / SRS) | Источник |
|---------------|----------------------------------------|----------|
| REQ-CART-01 | Пользователь может добавлять товары в корзину | US-CART-001 |
| REQ-CART-02 | Количество товаров в корзине отображается на иконке | SRS 4.2.1 |
| REQ-CART-03 | Пользователь может изменять количество товара в корзине | US-CART-002 |
| REQ-CART-04 | Пользователь может удалять товары из корзины | US-CART-003 |
| REQ-CART-05 | Итоговая стоимость пересчитывается при любом изменении | SRS 4.2.3 |
| REQ-CART-06 | Система корректно обрабатывает ошибки сети при работе с корзиной | SRS 4.2.5 |
| REQ-CART-07 | Приложение должно корректно работать на Android 8-14 и разных разрешениях | SRS 4.2.6 |
| REQ-CART-08 | Попытка перейти к оформлению с пустой корзиной должна блокироваться | SRS 4.2.7 |

**Заключение:**  
Набор тест-кейсов полностью покрывает все функциональные требования к корзине. Рекомендуется расширить негативные сценарии для сетевых ошибок и добавить тесты для граничных значений (максимальное количество товаров, большая корзина).
