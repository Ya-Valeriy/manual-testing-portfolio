# Чек-лист тестирования корзины интернет-магазина (мобильное приложение)

**Автор:** Валерий Яманкин  
**Дата:
**Версия приложения:  
**Цель:** Проверить корректность работы функционала выбора товара, добавления в корзину, управления корзиной, пересчёта стоимости и обработки сетевых ошибок.

---

## Предусловия
- Приложение установлено на тестовом устройстве.
- Пользователь не авторизован (гостевой режим) — если требуется, авторизация выполнена.
- Доступ к интернету стабилен (если не указано иное).
- В каталоге присутствуют товары с разными ценами и остатками.

---

## 1. Навигация и выбор товара (п. 1–3)

| № | Проверка | Ожидаемый результат | Статус (Pass/Fail) |
|---|----------|----------------------|---------------------|
| 1 | Выбрать категорию товара (например, «Электроника») | Открывается список товаров, относящихся к выбранной категории | |
| 2 | Проверить отображение карточек товаров | Каждый товар отображается с фото, названием, ценой, рейтингом (если есть) | |
| 3 | Открыть карточку выбранного товара (нажать на него) | Переход на страницу товара с подробным описанием, ценой, кнопкой «В корзину» | |

---

## 2. Добавление в корзину (п. 4–7)

| № | Проверка | Ожидаемый результат | Статус (Pass/Fail) |
|---|----------|----------------------|---------------------|
| 4 | Нажать «В корзину» на карточке товара | Товар добавляется в корзину; появляется уведомление об успешном добавлении | |
| 5 | Проверить обновление значка корзины (счётчика) | Количество товаров на иконке корзины увеличивается на 1 | |
| 6 | Перейти в корзину и проверить отображение добавленного товара | В списке корзины отображается добавленный товар с правильным названием, ценой и количеством (1) | |
| 7 | Повторить добавление **того же самого** товара 5 раз подряд | Каждый раз счётчик корзины увеличивается на 1, в корзине отображается количество = 5 (или суммируется) | |

---

## 3. Управление корзиной и пересчёт стоимости (п. 8–10)

| № | Проверка | Ожидаемый результат | Статус (Pass/Fail) |
|---|----------|----------------------|---------------------|
| 8 | Изменить количество товара в корзине (увеличить с 1 до 3) | Количество обновляется, итоговая стоимость пересчитывается корректно (цена × кол-во) | |
| 9 | Удалить один товар из корзины (нажать «Удалить» или крестик) | Товар исчезает из списка, счётчик корзины уменьшается, итоговая стоимость обновляется | |
| 10 | Добавить несколько разных товаров и проверить итоговую стоимость | Итоговая стоимость равна сумме цен всех товаров с учётом их количества (без скидок) | |

---

## 4. Обработка ошибок и сетевые сценарии (п. 11–19)

| № | Проверка | Ожидаемый результат | Статус (Pass/Fail) |
|---|----------|----------------------|---------------------|
| 11 | Добавление товара при обрыве связи (выключить Wi-Fi/мобильные данные во время запроса) | Приложение показывает понятное сообщение об ошибке («Нет соединения»), товар не добавляется, счётчик не меняется | |
| 12 | Добавление товара при смене сети (Wi-Fi → 4G или наоборот) во время запроса | Запрос завершается успешно (или повторяется автоматически) без потери данных и без дублирования товара | |
| 13 | Проверить работу приложения на разных версиях Android (например, 8, 10, 12, 14) | Все функции корзины работают стабильно, интерфейс не «плывёт», кнопки отзывчивы | |
| 14 | Проверить работу на разных устройствах (смартфон 5″, планшет 10″) | Отображение адаптируется под размер экрана, все элементы доступны, нет наложений | |
| 15 | Добавить товар при ограниченной скорости сети (эмулировать 2G/3G через DevTools или эмулятор) | Товар добавляется, но загрузка может идти дольше; при тайм-ауте показывается сообщение, но данные не теряются | |
| 16 | Попытка добавить товар при **полном отсутствии интернета** (офлайн-режим) | Приложение блокирует добавление, показывает ошибку «Нет подключения к интернету», корзина не меняется | |
| 17 | Имитация ошибки сервера (например, 500 Internal Server Error) при обновлении корзины | Приложение корректно обрабатывает ошибку, показывает сообщение, не теряет уже добавленные товары, позволяет повторить попытку | |
| 18 | Переход к оформлению заказа с **пустой корзиной** | Кнопка оформления неактивна или показывается предупреждение «Корзина пуста»; переход не происходит | |
| 19 | Удаление товара из корзины при **плохом соединении** (медленный интернет) | Приложение пытается отправить запрос, при ошибке показывает сообщение, но товар либо удаляется локально (с синхронизацией позже), либо остаётся — важно, чтобы не было рассинхрона между UI и сервером. Ожидаем: товар не дублируется, интерфейс не «зависает» | |
